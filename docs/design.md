## 2. 元件與按鈕規範 (Components)

### 2.1 輸入框
- 高度 52 px、圓角 14 px、水平內距 16 px。
- 背景色為 `Surface`，邊框 1 px `Line`。欄位錯誤時於正下方以 0.84 rem 內聯提示。

### 2.2 操作按鈕共用幾何 (Button Geometry)
「更換配色」、「下載圖片」、「清空資料」等核心動作統一採用相同規格：

| 項目 | 規範 |
|---|---|
| 高度 / 圓角 | 52 px / 14 px |
| 字級 / 字重 | `0.9rem` / 800 |
| 水平內距 | `0 18px` |
| 邊框 | 1 px border-box |
| 語意分色 | Primary（Action fill）、Secondary（Control tint / border）、Danger（清空資料固定紅灰警示） |

## 3. 版面佈局 (Layout)

- **Desktop (≥960px)**：雙欄佈局。左側固定分享卡預覽，右側為編輯表單。預覽下方操作列：更換配色在左、狀態在中、下載在右。
- **Mobile (<960px)**：單欄佈局。預設僅顯示卡片預覽；點選資訊區展開編輯表單。預覽下方操作列：狀態獨立置頂，更換配色與下載圖片等寬並列。
- **Header**：左側專案標題，右側 Ko-fi 贊助按鈕（桌面 134×36 px、手機 150×40 px 觸控範圍）。

## 4. 互動與動效 (Interactions & Motion)

- **主題切換器**：點擊「更換配色」展開浮層選單，預設向上開啟（空間不足時向下）。支援 Escape 或點擊外部關閉。
- **主題平滑切換**：切換主題時 UI 與預覽以 ~420ms ease-out 平滑過渡。首次載入已儲存主題時直接渲染，不播放過渡。
- **照片裁切導航器**：調整照片構圖時，右上角暫時顯示縮圖與裁切框，停止操作 2 秒後淡出。
- **顯影過渡**：Google Maps 自動抓取成功時，預覽區以 ~500ms 拍立得顯影淡入。
- **輸出邊界**：所有動效、過渡遮罩與導航器僅存於 DOM 預覽，不繪入輸出的 PNG 影像。
