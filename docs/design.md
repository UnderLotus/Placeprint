# UI 設計規範

## 1. Design Tokens

| Token | 數值 | 說明 |
|---|---|---|
| 主操作色 | `#087f8a` | 按鈕、重點連結、主要狀態 |
| 次要操作色 | `#DCEFEB`（Hover: `#C9E5E0`） | 次要按鈕底色 |
| 邊框色 | `#CFE1DE` | 控制項與分隔線邊框（1 px） |
| 輸入框背景 | `rgba(255, 255, 252, 0.82)` | 半透明淺米白 |
| 內文字色 | `#1b2a2a` | 主要文字 |
| 輔助字色 | `#607373` | 說明與次要資訊 |
| 錯誤字色 | `#9b3d38` | 驗證錯誤文字（0.84 rem） |

## 2. 元件尺寸

| 元件類型 | 高度 | 圓角 | 水平內距 |
|---|---|---|---|
| 主要控制項（輸入框、主下載按鈕） | 52 px | 14 px | 16 px（下載按鈕 18 px） |
| 輔助控制項（換圖、收合、清空） | 44 px | 12 px | 13–14 px |

- 表單欄位由等寬網格排列，頂部對齊，欄位間距 9 px，網格間距 20 px。
- 驗證錯誤於該欄位下方以內聯文字顯示，不阻擋其他無關操作。

## 3. 畫面佈局

- **Desktop (≥960px)**：雙欄佈局。左側固定分享卡即時預覽，右側為地點與內容編輯表單。
- **Mobile (<960px)**：單欄佈局。預設僅顯示卡片預覽；點選資訊區展開編輯表單並平滑捲動至編輯區。
- **Header**：左側專案標題，右側官方 Ko-fi 贊助按鈕（寬高約 134×36 px，手機端 150×40 px 觸控範圍）。

## 4. 互動與動效

- **照片裁切導航**：在照片區拖曳、縮放或聚焦微調時，右上角顯示縮圖與裁切框，停止操作 2 秒後淡出。
- **預覽顯影**：Google Maps 自動抓取成功時，預覽區以拍立得顯影淡入（約 500 ms 轉場）。
- **輸出邊界**：所有過渡動效、Ghost 佔位與導航器僅存在於 DOM 預覽，不繪入輸出的 PNG 影像。
